# GitHub Implementations

> **Selection rule:** Do not select repositories solely because they have many stars. Check documentation, source code, maintenance, reproducibility, license, examples, and connection to research.

## 1. Self-RAG

**Purpose:** Implementation associated with retrieval, generation, and self-reflection for grounded language generation.  
**Why relevant:** Directly related to retrieval-grounded generation and reducing unsupported model outputs.  
**Repository:** https://github.com/AkariAsai/self-rag

## 2. RAGFlow

**Purpose:** Retrieval-augmented generation framework focused on document understanding and grounded question answering.   
**Why relevant:** Demonstrates practical retrieval-grounded pipelines that can help address knowledge freshness.  
**Repository:** https://github.com/infiniflow/ragflow

## 3. Haystack

**Purpose:** Framework for building search, retrieval, question-answering, and RAG applications.  
**Why relevant:** Useful for constructing literature retrieval and evidence-grounded generation pipelines.  
**Repository:** https://github.com/deepset-ai/haystack

## 4. LlamaIndex

**Purpose:** Framework for connecting LLMs with external data and building retrieval-based applications.  
**Why relevant:** Useful for indexing and retrieving scholarly or document collections.  
**Repository:** https://github.com/run-llama/llama_index

## 5. LangChain

**Purpose:** Framework for composing LLM applications, including retrieval and tool-using pipelines.  
**Why relevant:** Provides building blocks for experimental literature-review and retrieval workflows.  
**Repository:** https://github.com/langchain-ai/langchain
