# Tools and Libraries

> **Verification note:** Confirm the current official project URL and maintenance status before final submission.

## 1. Crossref

Bibliographic metadata and DOI infrastructure useful for checking whether scholarly references and identifiers correspond to real publications.

Official: https://www.crossref.org/

## 2. Semantic Scholar

Scholarly search and metadata platform useful for discovering papers, authors, citations, and related research.

Official: https://www.semanticscholar.org/

## 3. OpenAlex

Open scholarly catalog useful for metadata discovery, citation relationships, authors, venues, and research entities.

Official: https://openalex.org/

## 4. arXiv

Open research repository particularly useful for rapidly evolving AI, machine learning, NLP, and related technical literature.

Official: https://arxiv.org/

## 5. Hugging Face

Platform providing models, datasets, evaluation resources, and tooling useful for LLM and NLP research.

Official: https://huggingface.co/
